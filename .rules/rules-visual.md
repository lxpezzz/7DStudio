REGLA DE CONSISTENCIA VISUAL

Antes de crear una nueva sección, analiza visualmente las secciones anteriores.

Reutiliza el sistema existente de:
- container width;
- padding lateral;
- tipografía;
- tamaños;
- border-radius;
- botones;
- colores;
- spacing;
- transiciones;
- grid.

No inventes una nueva dirección artística en cada componente.

Una sección nueva debe variar su composición, pero pertenecer claramente al mismo sistema visual.

Evita repetir exactamente el layout anterior.

JERARQUÍA DE ANCHURAS Y CONTENEDORES:
- Hero: Expansivo, amplio, asimétrico y con mayor presencia visual dentro del viewport.
- Secciones posteriores al Hero (ProductLoop, Soluciones, etc.): Utilizan obligatoriamente el contenedor centrado y controlado horizontalmente (.section-container / max-width: 1220px), dejando mayor aire lateral en pantallas grandes sin estirar el contenido indefinidamente.

Objetivo:
misma identidad, diferente composición, jerarquía espacial clara.
