REGLA DE COMPONENTIZACIÓN

Crea un componente cuando exista al menos una de estas razones:
- es una sección independiente;
- se reutiliza;
- tiene lógica propia;
- tiene interacción propia;
- mejora claramente la mantenibilidad.

No crees componentes únicamente para:
- un título;
- un botón único;
- un icono;
- un wrapper;
- tres líneas de HTML usadas una sola vez.

Evita tanto componentes gigantes como microcomponentes innecesarios.

Prioriza componentes de tamaño lógico y fácil comprensión.
