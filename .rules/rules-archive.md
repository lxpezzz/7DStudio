REGLA DE ARCHIVOS

No crees archivos, componentes, JSON, utilities, helpers, hooks o estilos para funcionalidades que todavía no existen.

Crea únicamente lo necesario para la fase actual.

No prepares:
- componentes vacíos;
- futuras secciones;
- archivos placeholder;
- abstracciones anticipadas;
- utilities que todavía no se utilizan.

Si posteriormente necesitamos esa funcionalidad, la crearemos entonces.

Cada archivo nuevo debe tener una función real dentro de la implementación actual.
